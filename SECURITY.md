# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities **privately** to **matthew@ohhey.ca**.

Do not open a public GitHub issue for a security vulnerability.

We aim to acknowledge reports within **7 days** (best effort) and will keep you
updated as we investigate and fix.

## Supported versions

Security fixes are applied to the **latest `main`**. There are no separate
maintained release branches at this time.
